# @dalily/mobile — Sprint 9 Phase 1 foundation

## Quick start

```bash
cd mobile
cp .env.example .env
# fill EXPO_PUBLIC_SUPABASE_URL + EXPO_PUBLIC_SUPABASE_ANON_KEY
npm install --legacy-peer-deps
npm run verify
npm start
```

## Scripts

- `npm start` — Expo dev server
- `npm run typecheck`
- `npm run lint`
- `npm run verify` — architecture invariants

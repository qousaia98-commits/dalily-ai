# Google Play Data Safety — Dalily

Use this when filling the Play Console Data safety form.

## Data collected

| Data type | Collected | Shared | Purpose | Optional |
|-----------|-----------|--------|---------|----------|
| Email | Yes | No | Account | No |
| Name | Yes | No | Account / bookings | No |
| Precise location | Yes | No | Nearby search, navigation | Yes (permission) |
| Photos | Yes | No | Attachments / gallery | Yes |
| App interactions | Yes | No | Analytics (consent) | Yes |
| Crash logs | Yes | No | Stability | Yes (consent) |
| Device IDs | Yes | No | Push delivery | No |

## Security practices

- Data encrypted in transit (TLS)
- Users can request deletion
- Users can request export
- Committed to Play Families policy: N/A (not primarily child-directed)

## Data deletion

In-app: Profile → Privacy → Request account deletion  
Web: https://dalily.app/privacy  
Email: support@dalily.app
